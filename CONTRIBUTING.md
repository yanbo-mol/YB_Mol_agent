# Feedback and documentation / 反馈与文档贡献

This repository accepts product feedback, reproducible bug reports, example suggestions and documentation improvements for **YB_MOL Studio**. Core application source code is not distributed here.

欢迎提交产品反馈、可复现问题、案例建议和文档改进；这里不分发核心应用源码。

- [Report a bug / 提交问题](https://github.com/yanbo-mol/YB_Mol_agent/issues/new?template=bug_report.yml): include the installer version, Windows version, reproduction steps, expected and actual results. For model errors, include the provider/model and error code, never the key.
- [Suggest a workflow / 提出需求](https://github.com/yanbo-mol/YB_Mol_agent/issues/new?template=feature_request.yml): explain your scientific task, current obstacle and desired outcome.
- Documentation pull requests should preserve the product name **YB_MOL Studio**, accurate historical citations and version-specific limitations. Use real evidence for examples and identify any accelerated recordings.

Only share files you are authorized to publish. Remove credentials, device activation details and private research information. Contact [zhaoyanbo@ccbiomol.com](mailto:zhaoyanbo@ccbiomol.com) for activation/collaboration, and use [SECURITY.md](SECURITY.md) for vulnerabilities.
