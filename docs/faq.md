# FAQ / 常见问题

**Which file should I download? / 应该下载哪个文件？**<br />
The `.exe` on the [selected release](https://github.com/yanbo-mol/YB_Mol_agent/releases/tag/v0.1.0-preview.656a16e02897); not the source-code ZIP. / 下载对应发布页的 `.exe`，不是 Source code 压缩包。

**Is the software open source? / 软件开源吗？**<br />
This repository distributes installers, documentation and examples. The core application code is not included. / 这里分发安装包、文档和案例，不包含核心应用源码。

**Can I use it without programming? / 不写代码也可以用吗？**<br />
You can inspect and edit structures through the interface and describe tasks to YB_Agent. Advanced calculations can still require scientific configuration and domain judgment. / 可以通过界面查看和编辑结构，用自然语言给 Agent 任务；高级计算仍需要科学计算配置与专业判断。

**Can experts work manually? / 专家能手动设计吗？**<br />
Yes. Direct manipulation and precise selection are part of the workspace; you can continue from an agent-produced structure yourself. / 可以。平台支持直接操作和精确选择，也支持接着 Agent 的结果手动修改。

**Is downloading the installer enough? / 下载后就全部能用吗？**<br />
An activation step may be required. Agent tasks need a configured model; external APIs and computation may have separate fees. See [installation](installation.md). / 可能需要设备激活。Agent 需要配置模型，外部 API 和计算资源可能另外收费，参见[安装说明](installation.md)。

**Why do older screenshots show another name? / 为什么截图中名称不同？**<br />
The current product name is **YB_MOL Studio**. Historical captures, published paper titles and existing installer filenames are preserved accurately. / 当前产品名称统一为 **YB_MOL Studio**；历史截图、已发表论文标题和已有安装包文件名保留原样。

**Do the examples prove scientific performance? / 案例证明科学性能吗？**<br />
The examples show specific structural operations and saved outputs. They do not prove efficacy, expression improvement, binding affinity or catalytic activity. / 案例展示具体结构操作与保存结果，不等同于验证药效、表达提升、结合亲和力或催化活性。

**How do I report a problem? / 如何反馈？**<br />
Use [the issue forms](https://github.com/yanbo-mol/YB_Mol_agent/issues/new/choose), with version, expected result, actual result and a minimal reproduction. Share only data you can publish. Activation questions go to [zhaoyanbo@ccbiomol.com](mailto:zhaoyanbo@ccbiomol.com); security reports follow [SECURITY.md](../SECURITY.md).

使用 [Issue 表单](https://github.com/yanbo-mol/YB_Mol_agent/issues/new/choose)，提供版本、预期结果、实际结果和最小复现；仅上传可公开数据。激活问题请邮件联系，安全问题按 [SECURITY.md](../SECURITY.md) 私下反馈。
