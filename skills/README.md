# YB_MOL Studio protected Skills

Each ZIP contains one independently protected Skill. Packages are grouped by domain; names and descriptions are retained in catalog.json. Install with the official yb_agent runtime. Scientific engines and their dependencies remain separate requirements.

Compiled program entries and runtime data use ordinary files and paths. Detailed workflow documents use native encrypted-document access. Consult each Skill for its platform and interpreter requirements.
